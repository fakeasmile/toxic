# 从源头重新审视：有害言论检测 + 可解释AI

> 日期：2026-06-01
> 触发：黑盒分类器 F1=0.8282，12 个方案无一突破 0.83
> 结论：**瓶颈不在架构，在表示空间**

---

## 一、12 个方案为什么全部失败——真正的根因

### 1.1 错误分析揭示的决定性证据

黑盒分类器（F1=0.8282）的 412 个错误样本：

| 错误类型 | 数量 | 关键特征 |
|---------|------|---------|
| FP（非毒→误判毒） | **226** | **100% 来自 expression=0（讨论敏感话题但无毒）** |
| FN（漏判毒） | 186 | expression=0 FN率22.6%, expression=2 FN率20.9% |

**核心发现：模型把"讨论敏感话题"等同于"对敏感话题进行有毒攻击"。**

- 226 个 FP 全部是讨论 race/gender/region/lgbt 但并非有毒的样本
- RoBERTa 无法区分"提到种族"和"种族歧视"
- 这不是概念瓶颈问题、不是信息压缩问题、不是残差路径问题——**是表示空间本身的问题**

### 1.2 之前所有方案为什么都在 0.78-0.83 徘徊

| 方案 | F1 | 失败归因（之前） | 真正原因 |
|------|-----|----------------|---------|
| main (纯MLP) | 0.7823 | 无PLM文本编码 | LLM概念评分对隐式毒性失效 |
| rcwn | 0.7851 | 残差路径架空概念 | RoBERTa表示本身无法区分话题和毒性 |
| lrd-cbm | 0.8168 | 1536→56瓶颈压缩 | 瓶颈不是问题，输入表示就有偏 |
| cotd-cbm | 0.8205 | 残差后门 | 残差路径读到的也是偏的表示 |
| hecd-net | 0.8165 | 概念从CLS学无新信息 | CLS本身就混淆了话题和毒性 |
| ki-scb | 0.8269 | 概念9→128 vs 残差1536→128 | 9维结构化概念无法纠正768维的偏 |
| cgrm | 0.79 | 概念-Token对齐无监督 | Token表示本身就有偏 |
| ttt-cbm | 0.8145 | MLM与毒性目标不一致 | TTT微调的表示仍然混淆话题和毒性 |
| scbm-llm | NaN | dtype不匹配 | 即使修好，LLM中间层同样混淆 |
| tscd-v2 | ~0.81 | 多阶段蒸馏信号衰减 | 教师模型的表示就有偏 |
| pgl-cbm | 未运行 | 拼音/字形无效 | 方向错误 |
| **黑盒分类器** | **0.8282** | — | **无概念瓶颈，纯RoBERTa天花板就是0.83** |

**统一根因：RoBERTa 的表示空间混淆了"话题"和"毒性"两个维度。所有在 RoBERTa 表示之上构建的方案，无论架构如何精巧，都无法突破这个表示空间的天花板。**

### 1.3 为什么 SCBM 在英文上有效

英文数据集（ELF22, HS-CS）以显式毒性为主，有毒文本和无毒文本在话题维度上的分布差异不大——有毒文本通常包含明确的侮辱词（"idiot", "racist"），无毒文本不包含。RoBERTa 可以仅凭词汇特征区分，不需要理解"话题 vs 毒性"的区别。

中文 TOXICN 以隐式毒性为主，有毒文本和无毒文本**在话题维度上高度重叠**——都在讨论 race/gender/region/lgbt，区别仅在于**语用态度**（是客观讨论还是恶意攻击）。RoBERTa 的预训练语料没有教它区分这种细微的语用差异。

## 二、根本性重新审视

### 2.1 问题的本质

**之前所有方案都在问："如何在 RoBERTa 的表示空间上构建更好的分类器？"**

**正确的问题应该是："如何改变 RoBERTa 的表示空间，使其能够区分话题和毒性？"**

这不是架构问题，不是损失函数问题，不是概念瓶颈问题——**是表示学习问题**。

### 2.2 从 CV 领域的类比

在 CV 中，类似的问题已经被深入研究：

- **问题**：图像分类器混淆"背景"和"目标"（如把草地背景中的牛分类为"草地"）
- **解决方案**：对抗去偏（移除背景信息）+ 对比学习（强制分离同背景不同目标的样本）
- **NLP 对应**：混淆"话题"和"毒性" → 对抗去偏（移除话题信息）+ 对比学习（强制分离同话题不同毒性的样本）

### 2.3 可解释性的正确位置

之前所有方案都试图**在训练中同时实现高性能和可解释性**，这导致了概念层被架空的必然结果。

**正确的范式**：
1. **先**通过表示学习突破性能瓶颈（F1 > 0.84）
2. **再**在训练好的高性能模型上提取可解释概念（事后提取）

可解释性不应在训练中强加，而应在训练后提取。这是 PCBM（ICLR 2024）的核心洞察。

## 三、新方案：TAD-CL（Topic-Adversarial Debiasing + Contrastive Learning）

### 3.1 核心思想

**通过对比学习+对抗去偏，改变 RoBERTa 的表示空间，使其能够区分"讨论敏感话题"和"对敏感话题进行有毒攻击"。**

### 3.2 架构

```
输入文本
    ↓
[RoBERTa Encoder] → h [B, 768]
    ↓
[投影头] → z [B, 128]  （用于对比学习）
    ↓
三重训练目标：
    ├── [毒性分类头] → toxic_logits [B, 2]     ← CE损失
    ├── [话题对抗头] → topic_logits [B, 4]      ← 对抗损失（梯度反转）
    └── [对比损失] SupCon(z, toxic_label)        ← 拉近同类、推远异类

训练策略：
    ├── 难负样本挖掘：同话题不同毒性的样本对
    ├── 课程学习：先显式毒性(expression=1) → 后隐式(expression=0,2,3)
    └── 对抗去偏：梯度反转层(GRL)阻止话题信息流入毒性表示
```

### 3.3 三重损失函数

```
L_total = L_CE(toxic) + λ_supcon * L_SupCon(z, toxic) + λ_adv * L_adv(topic)

其中：
- L_CE: 标准交叉熵损失（毒性分类）
- L_SupCon: 监督对比损失（同类毒性拉近，异类推远）
- L_adv: 对抗损失（通过GRL，让编码器最大化话题分类损失）
```

### 3.4 为什么这次可能成功

| 之前方案 | TAD-CL |
|---------|--------|
| 在偏的表示空间上构建分类器 | **先纠正表示空间的偏** |
| 概念层被残差路径架空 | **无概念层，纯表示学习** |
| LLM Likert 评分对隐式毒性失效 | **不依赖 LLM 评分** |
| 模型混淆话题和毒性 | **对抗去偏强制分离话题和毒性** |
| 同话题有毒/无毒样本表示接近 | **SupCon + 难负样本强制推远** |
| 隐式毒性样本被忽略 | **课程学习逐步引入难样本** |

### 3.5 预期效果

基于文献调研的保守估计：

| 方法 | 预期增益 | 来源 |
|------|---------|------|
| SupCon + 话题难负样本 | +1.5-2.5% F1 | Hard-Negative CL (NAACL 2024): +4.2% |
| 对抗去偏 | +0.5-1.5% F1 | BTE (ACL 2024): FP率从18.7%降至6.3% |
| 课程学习 | +1-2% F1 | SPL (AAAI 2024): +4.3% |
| **组合** | **+3-5% F1** | **预期 F1 = 0.85-0.87** |

### 3.6 可解释性方案（性能达标后）

一旦 TAD-CL 达到 F1 > 0.84，在训练好的模型上事后提取概念：

1. **结构化概念探测**：线性探针从 h 中提取 topic/expression/intent/tone
2. **句子嵌入概念评分**：用 bge-base-zh 计算文本-概念相似度
3. **直接线性分类**：概念向量 → 线性层 → 有毒/无毒（DCR 防绕过）

## 四、实施计划

### Phase 1：TAD-CL 核心实现（1-2 天）

1. 修改 `blackbox_classifier.py`：加入投影头 + 话题对抗头 + GRL
2. 修改 `blackbox_pipeline.py`：加入 SupCon 损失 + 难负样本采样 + 课程学习
3. 训练 + 评估

### Phase 2：超参数调优（1 天）

- λ_supcon: 0.1 → 1.0
- λ_adv: 0.1 → 1.0
- SupCon 温度 τ: 0.05 → 0.2
- 课程学习策略：linear / baby_step / self_paced

### Phase 3：可解释性提取（1-2 天，性能达标后）

- 结构化概念探测
- 句子嵌入概念评分
- 直接线性分类
