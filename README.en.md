# toxicnew

A Chinese toxic speech detection system based on **type-aware concept bottleneck models**.

This repository is the current main branch of the project: it focuses on **v4 type-aware multi-concept vectors** (`generate_typed_concept_vllm.py`). Concept vectors generated by an upstream LLM are fed into an interpretable concept bottleneck layer before the classifier, achieving **both performance and intrinsic interpretability**.

> History: The v1 (5-level Likert) scripts are kept in `scripts/` for reference but are not part of the downstream pipeline. The v2 three-level behavioral-anchoring version has been moved to `d:\fscbm` and produced the paper ACV-FSCBM (ToxiCN weighted F1=0.817).

## Pipeline

```
raw text → type-aware concept vectors (vLLM) → feature extraction (concept_features) → MLP classifier → toxic/non-toxic
```

## Type-aware concept vector generation

`generate_typed_concept_vllm.py` uses the v4 mixed concept dictionary (134 concepts, 7 semantic types). Each type gets its **own prompt template and verbalizer** to extract more information from the LLM.

| Type | #Concepts | Verbalizer | Scalar score |
|------|-----------|-----------|--------------|
| behavior | 27 | binary ["1","2"] | P(2) |
| strategy | 25 | binary ["1","2"] | P(2) |
| evaluation | 16 | 3-level ["1","2","3"] | P(3) |
| discrimination | 33 | 3-level ["1","2","3"] | P(3) |
| neutral | 6 | 3-level ["1","2","3"] | P(3) |
| intent | 15 | binary ["1","2"] | P(2) |
| effect | 12 | binary ["1","2"] | P(2) |

- vLLM inference (max_tokens=1, temperature=0, logprobs=20)
- extract verbalizer-token probabilities from first-token logprobs, softmax-normalized
- `concept_scores`: unified "harmful/affirmative" probability [0,1]; `level_probs`: full raw probabilities

## Feature extraction

`concept_features.py` extracts the feature matrix from `level_probs` according to `concept_feat_mode`:

| Mode | Binary-type features | 3-level-type features | Notes |
|------|---------------------|-----------------------|-------|
| single | P(2) | P(3) | most compact |
| conditional | P(2) | P(3)+P(3)/(P(2)+P(3)) | current default, `concept_feat_mode=conditional` |
| all_probs | P(1),P(2) | P(1),P(2),P(3) | all info, highest dim |

## MLP architectures

- **MLP (GatedMLP, standard)**: gated(sigmoid) → Dropout → FC→96 → ReLU → Dropout → FC→2
- **TypeAugmentedGatedMLP**: adds per-type summary features (mean/max) on top of gating

## Configuration

Training hyper-parameters are set in `configs/MLP_config.py`:

| Param | Description | Default |
|-------|-------------|---------|
| `concept_feat_mode` | feature extraction mode | conditional |
| `model_type` | mlp / type_augmented_gated_mlp | mlp |
| `batch_size` | batch size | 16 |
| `epochs` | training epochs | 200 |
| `max_lr` | peak learning rate | 1e-3 |
| `pct_start` / `div_factor` / `final_div_factor` / `anneal_strategy` | OneCycleLR params | 0.2 / 25 / 10000 / cos |
| `dropout_rate` | dropout rate | 0.5 |
| `hidden_features` | hidden dim | 96 |
| `patience` | early stopping patience | 20 |
| `seed` / `use_deterministic` | random seed / deterministic mode | 1 / False |

## Usage

**Step 1: generate concept vectors**

```bash
python scripts/generate_typed_concept_vllm.py --mode train --dataset_name TOXICN --model_name glm-4-9b-chat
python scripts/generate_typed_concept_vllm.py --mode test  --dataset_name TOXICN --model_name glm-4-9b-chat
```

Output: `data/processed/<dataset>/<model>/concept_{train,test}_<model>_typed_v4.json`

**Step 2: train & test**

```bash
# train + test
python utils/mlp_pipeline.py --mode all --dataset_name TOXICN --model_name glm-4-9b-chat

# train only
python utils/mlp_pipeline.py --mode train --dataset_name TOXICN --model_name glm-4-9b-chat

# test only (requires experiment timestamp)
python utils/mlp_pipeline.py --mode test --dataset_name TOXICN --model_name glm-4-9b-chat --timestamp <timestamp>
```

## CLI arguments (mlp_pipeline.py)

| Argument | Description | Required |
|----------|-------------|----------|
| `--mode` | all / train / test | default all |
| `--dataset_name` | TOXICN / COLD | yes |
| `--model_name` | LLM used to generate concept vectors | yes |
| `--timestamp` | experiment timestamp for test mode | required for test |
| `--adjective_name` | concept dictionary file | no, default toxic_adjectives_v4.csv |
| `--model_type` | mlp / type_augmented_gated_mlp | no, default mlp |

Priority: in train mode CLI > MLP_config.py; in test mode the experiment's `config.json` is used.

## Experiment output

```
experiments/<timestamp>/
├── config.json              # full experiment snapshot (concept vectors + classifier + hyper-params + data size)
├── best_model.pth           # best model weights
├── metrics.png              # training curves
└── test_results/            # test results
    ├── metrics.json         # metrics
    ├── classification_report.txt
    └── predictions.json     # per-sample predictions
```

`config.json` records "which concept vectors and classifier": `dataset_name/model_name/adjective_path/concept_feat_mode/num_concepts/concept_dim` locate the upstream concept vectors, `model_type/hidden_features/dropout_rate` locate the downstream classifier.
